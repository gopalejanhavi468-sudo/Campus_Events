About This Project

Web Technology Mini-Project for B.Tech Computer Engineering curriculum.

Project Overview

This website was developed as a Web Technology mini-project to provide college students with a simple, centralized platform to explore campus events, workshops, and competitions, and register online without needing paper forms.

Why Online Registration?

Manual paper registrations during college fests often lead to long queues, misplaced entry slips, and data entry mistakes. An online registration website allows students to quickly check event details, verify schedule compatibility, and complete registration with instant digital confirmation receipts.

Web Technology Concepts Demonstrated

  • HTML5: Semantic tags (<header>, <nav>, <main>, <footer>, <section>), structured form controls, and accessible input types.
  • CSS3 Styling & Layouts: Flexbox, CSS Grid layout systems, custom variables, hover micro-interactions, and print media queries.
  • Responsive Web Design: Mobile-first hamburger navigation and adaptive card grids for desktops, tablets, and smartphones.
  • JavaScript DOM Manipulation: Dynamic event card rendering, real-time search, category filtering, and URL query parameter parsing.
  • Client-Side Validation: Form input checking, custom email and 10-digit Indian mobile regex validation without relying on alert popups.
  • Browser LocalStorage: Client-side registration data persistence and generation of unique registration IDs.

Implementation Note

This version of the project is built using pure frontend web technologies (HTML5, CSS3, JavaScript ES6) and runs directly in any modern web browser or GitHub Pages without requiring server-side backend frameworks or databases.
